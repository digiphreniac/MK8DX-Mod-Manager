How this works
When two selected mods change the same file you can keep one mod's copy, use the game's own file, or leave just those files out of one mod - the rest of the mod still works. Leave-outs are remembered, even across re-downloads, and every mod's popup has a "Files" button (in a character's mod list it is "Edit included files" in the row's ... menu) to leave out any single file.
