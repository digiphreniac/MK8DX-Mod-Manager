Settings

Master Directory
Where this app keeps your downloads and all its own settings/cache files. Changing it lets you optionally bring your existing files along to the new folder.
UI icons & text
UI Icon Worklist
Every downloaded mod that's UI art or a packed .sarc with no romfs (character icon sets, loading-screen/theme archives, ...) - can't be merged automatically. Use an external tool like Switch Toolbox to inject the icons into your combined set at ui-icons/romfs/UI/cmn/. A whole-file .sarc from a theme is a full replacement of that set, so start from it deliberately rather than layering it over your own icon work.

Game version
Code patches (exefs .ips files, e.g. most Mechanics mods) only work on the exact game version they were built for, and do nothing - with no error - on any other. Enter your game's build ID (the name of its .ips patch files / cheat files, found on cheat databases for your version) to have patches for a different version flagged as "wrong game version". Leave empty to skip the check.
Your game's files (for menu icons & names)
GameBanana Browsing
When off, mods GameBanana marks with a content visibility rating are hidden from "Browse GameBanana" lists and searches. Pasting a direct link to a specific mod always works regardless of this setting.
Character Select
Off by default. When on, each character tile shows a badge like 1/4 (mods ticked / mods downloaded). When off, a tile that has mods downloaded but none ticked gets a small hollow ring instead, and hovering a tile still tells you the numbers.
On by default. Each time you click a character's tile, and when a character's mod becomes finished (its name and icons checked, or nothing to check), the app plays the character-select voice from its ticked mods - the sound the game makes when you pick it - and the speaker on its tile lights up while it plays. Nothing plays for a character whose mods don't include one.
Advanced
Shows extra technical detail (for example the full list of files in a conflict is open by default). Nothing essential is hidden without it - conflicts and left-out files are always available in the section below.
Conflicts & left-out files
When two checked mods change the same file you can keep one mod's copy, use the game's own file, or leave just those files out of one mod - the rest of the mod still works. Leave-outs are remembered, even across re-downloads, and every mod's popup has a "Files" button (in a character's mod list it is "Edit included files" in the row's ... menu) to leave out any single file.

Maintenance
