UI Icon Worklist
Every downloaded mod that's UI art or a packed .sarc with no romfs (character icon sets, loading-screen/theme archives, ...) - can't be merged automatically. Use an external tool like Switch Toolbox to inject the icons into your combined set at ui-icons/romfs/UI/cmn/. A whole-file .sarc from a theme is a full replacement of that set, so start from it deliberately rather than layering it over your own icon work.
