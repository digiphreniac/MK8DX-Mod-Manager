What the labels on a mod mean
UI art only
The mod is just menu pictures, or a packed common.sarc/menu.sarc, with no romfs folder, so it can't be added directly. See "UI Icon Worklist" in Settings.
Needs romfs folder
The mod's folders (Driver, Kart, Audio...) aren't inside a romfs folder. Open its folder, create a romfs folder, and move them in.
Needs manual fix
The mod unpacked, but the app couldn't tell what's in it. Open its folder and take a look.
Packed archive only
Everything in the mod is a packed .sarc file. A commit never copies those in (they'd overwrite every other icon and name), so on its own selecting it does nothing.
Code patch
Changes the game's program instead of adding files (most "Mechanics" mods are this). It only works on the game version it was made for and does nothing on any other, so set your version in Setup. "Select All" skips these, so select each one yourself.
Slot / music mismatch
A course mod's files match a different course than the one you downloaded it for, so it may belong under another course.
Voice: mute a line or use your own sound
Editing a voice
Every character's card has a Voice row with Edit voice lines. For any line you can Mute it, or Use my own sound: choose an audio file (mp3, wav, ogg or m4a), pick the part you want, and the app converts it for the game (up to 8 seconds). Mute all silences every line at once, and Undo all changes puts everything back.
Where your changes go
They're saved as a mod called Custom voice under that character. Select, deselect or remove it like any other mod, and Commit includes it.
Known issues and clashes
A modded course feels like it's playing in slow motion
This is a known problem called the "Slow Motion Bug". The game's physics are tied to the frame rate, so a track with more geometry or effects than the Switch can handle slows the whole race down. It's most common in tracks ported from other games, and it comes from the mod itself, so this app can't fix it. See the Custom Mario Kart wiki's Slow Motion Bug page.
A modded character's icon or a course's name still looks like the original
Commit again after changing your mods, and check that the language in Settings matches your Switch's language, because the menu text is built for that one language.
A deselected mod's picture or name still shows in the game
Copying the staging folder onto an SD card that already has an older copy only adds and replaces files, so files from a mod you've since deselected stay behind. Delete atmosphere/contents/0100152000022000/romfs on the SD card (or your emulator's mod folder) first, then copy the fresh staging folder over.
Two mods clash
A clash means two selected mods write different content to the same file. Settle it on the Commit page with one click: keep one mod's version, use the game's own file, or deselect a mod. Only the clashing files are affected, and your choice is remembered. Every mod's card has a Files button to leave out any single file yourself, and Settings lists every leave-out with an "Include again" button. Two code patches that overlap can't be split, so one of them has to be deselected.
If something goes wrong
Copy the details and paste them where you report the problem. They hold the app and Windows versions, your game version and language, the state of your game files, and the end of the app's log. Your Windows user name is left out. The log is the file mod-manager.log next to the app, and the run before is kept as mod-manager.previous.log.
