Known issues
A modded course feels like it's playing in slow motion
Very heavy tracks can run in slow motion on the Switch. This comes from the track itself, not the app, so tell the track's author, or ask on the Discord.
A character's icon or a course's name still looks like the original
Commit again after changing your mods. Also check that the language in Settings is the one your Switch uses, because the menu text is only built for that language.
A mod I deselected still shows up in the game
Copying onto an SD card only adds and replaces files, so a deselected mod's files stay behind. Delete atmosphere/contents/0100152000022000/romfs on the SD card (or in your emulator's mod folder) first, then copy the staging folder again.
